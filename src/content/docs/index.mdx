Rift lets you move, resize, and rearrange windows from the keyboard. Choose from several layout styles and give different parts of your workflow their own virtual workspaces.

## Arrange windows without the mouse

Rift tiles the windows on your desktop and keeps them organized as you open, close, and move between apps.

<CardGrid>
  <Card title="Keyboard-driven" icon="laptop">
    Focus, move, resize, float, and swap windows with shortcuts. Press Option + Z to tile the current desktop.
  </Card>
  <Card title="Five layouts" icon="window">
    Use familiar split-screen tiling, scrolling columns, master-stack, and more, everywhere or per workspace.
  </Card>
  <Card title="Virtual workspaces" icon="desktop">
    Give coding, reading, or chat its own workspace within a macOS Space, and let app rules place windows automatically.
  </Card>
  <Card title="Ready without configuration" icon="setting">
    The bundled configuration works out of the box. When you want changes, one TOML file covers settings and shortcuts.
  </Card>
</CardGrid>

## Try Rift

Install Rift, grant macOS Accessibility permission, and press Option + Z to tile the windows on your current desktop. You do not need to write a configuration file before trying it.

## Choose how windows are arranged

Rift includes five layouts, from familiar split-screen tiling to scrolling columns and master-stack. Choose one layout everywhere or assign different layouts to individual workspaces. App rules can place windows automatically, while floating mode keeps dialogs and utility windows out of the tiled layout.
